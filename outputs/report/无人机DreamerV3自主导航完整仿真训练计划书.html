1. 项目定位与研究边界

本项目以四旋翼无人机为唯一对象，在含静态障碍、慢速动态障碍及少量强制冲突障碍的三维仿真空间中，研究基于DreamerV3世界模型的局部目标自主导航与动态避障。策略从结构化环境观测直接生成三维速度和偏航角速度指令；姿态稳定、电机分配和刚体运动由确定性底层控制器与物理引擎完成。

项目以PyBullet为大规模训练与批量评测平台，以ROS 2、PX4 SITL和Gazebo为控制链路及动力学适配验证平台。研究结论限定于仿真证据，不外推为真实环境安全性或Sim2Real成功。

术语本项目定义
端到端导航从结构化感知与自身状态直接输出任务层速度指令，不指像素直接控制电机。
自主导航已知局部目标点条件下，无碰撞、未越界地限时到达；不包含SLAM和全局规划。
动态避障对运动障碍在线感知与决策，形成绕行、减速或等待，不要求显式输出未来轨迹。
复杂动态环境16×16×5米空间、12个慢速动态障碍以及0～2个横穿、迎面或垂直强制冲突障碍。

不作为主线的内容

  • 不做RGB图像端到端、目标检测、视觉跟踪、SLAM和全局地图规划。
  • 不增加独立LSTM/Transformer轨迹预测器，运动信息由RSSM隐状态建模。
  • 不让强化学习直接输出四电机转速；底层姿态稳定使用确定性飞控。
  • 不在Gazebo中从零大规模训练，不把实机飞行列为本阶段必做验收。
  • 自动降落作为工程状态机，不与纯导航算法收益混为一谈。

2. 研究目标与预期贡献

总体目标是构建可复现、符合四旋翼动力学、可与PPO公平比较的DreamerV3导航系统，使无人机在稠密慢动态障碍与突发强制冲突共存的环境中平稳到达目标，并完成软件在环迁移验证。

核心研究问题

  1. RSSM能否从短时LiDAR、自身运动和障碍相对状态中学习有用的动态环境模型？
  2. DreamerV3是否能以更少环境交互达到与PPO相当或更好的动态避障性能？
  3. 世界模型能否改善迎面、双横穿和垂直冲突中的提前避让、最小净空与尾部风险？
  4. 世界模型、时序观测、威胁排序和安全投影各自贡献多少？
  5. 策略在噪声、延迟、轨迹变化和轻微动力学偏差下是否保持可接受性能？

贡献定位

  • 面向四旋翼动态导航的DreamerV3环境适配、训练课程和系统化评测流程。
  • “稠密慢障碍＋少量高威胁冲突”的场景设计，兼顾可预测性与真实避障检验。
  • 相同动力学、观测、动作、奖励和测试种子下的DreamerV3/PPO公平比较。
  • 世界模型、短时观测、威胁排序和安全投影的分层消融。
贡献不表述为发明全新DreamerV3，而表述为动态无人机导航中的世界模型实现、训练方法、风险分析和仿真验证。

6. 四旋翼动力学与分层控制

策略不得直接修改无人机位置、姿态或速度。每个10 Hz动作先经过限幅和加速度限制，再由速度—姿态级联控制器计算总推力与姿态力矩，经CF2X电机混控和电机响应施加于刚体，由PyBullet以240 Hz积分。

参数早期课程最终配置
水平速度0.6 m/s1.0 m/s
垂直速度0.3 m/s0.4 m/s
偏航角速度0.5 rad/s0.5 rad/s
水平加速度0.6～1.0 m/s²1.5 m/s²
垂直加速度0.3～0.5 m/s²0.6 m/s²
决策/物理频率10/240 Hz10/240 Hz
起飞 → 定点悬停 → 导航/避障 → 停机坪上空对准 → 稳定保持 → 分段下降 → 接触确认 → 停桨

强化学习负责导航避障；起飞、终端悬停、下降、接触和停桨使用确定性状态机。后续增加障碍侵入或姿态异常时的复飞逻辑。

7. 观测、动作、奖励与终止接口

统一观测

  • 自身位置、姿态四元数、世界系线速度和机体系角速度。
  • 目标相对位置、距离及必要边界信息。
  • 16线水平环形LiDAR，固定量程并归一化。
  • 威胁排序后的3个关键障碍相对位置、尺寸和相对速度，不足补零。
  • 上一步实际动作。
  • 主时序实验使用8帧LiDAR/障碍历史，单帧、4帧和8帧作为消融。

统一动作

a = [vx_world, vy_world, vz_world, yaw_rate]，统一归一化至[-1,1]

主接口采用局部世界系速度，以匹配目标定义和PX4 Offboard局部速度控制。机体系动作仅作为偏航不变性消融。

六项主奖励

r = r_progress + r_goal + r_collision + r_danger + r_time + r_smooth
奖励原则对应指标
进度相邻决策目标距离减少量距离、路径效率
到达满足目标半径与稳定性后一次性奖励成功率
碰撞/越界物理接触或出界终止惩罚碰撞率、越界率
危险距离净空低于阈值的连续惩罚最小净空
时间每步固定小惩罚导航时间
动作变化惩罚相邻实际动作差平稳性

TTC、边界软惩罚、到达速度奖励和安全投影不得混入主算法比较，分别作为消融或工程增强；降落奖励不进入纯导航主表。

终止语义

  • 成功：限时、无碰撞、未越界并进入目标区域；稳定到达同时满足速度和保持时间。
  • is_terminal：成功、碰撞或越界；截断：仅达到最大步数。
  • DreamerV3必须区分真实终止与超时，正确学习连续性。

8. DreamerV3与PPO算法方案

Encoder → RSSM（确定性状态＋离散随机状态）→ Decoder / Reward / Continue
RSSM潜在状态 → 想象H步 → Actor-Critic更新

早期使用约1M参数小模型；进入多动态障碍后再评估约12M参数。扩模必须在相同数据预算下消融，不能把更多参数的收益等同于世界模型机制收益。

PPO使用相同观测、动作、奖励、终止、训练分布和测试实例。最佳PPO可用于Replay演示数据，但其动作不得混入DreamerV3在线评测。

每阶段只增加一个主要难度来源，以固定种子确定性评测晋级，不以训练回报或精选视频晋级。

最终场景混合

  • 50%：12个普通慢动态障碍。
  • 25%：12慢障碍＋1个随机冲突。
  • 25%：12慢障碍＋2个随机冲突。

10. 数据、Replay与检查点管理

  • 每个transition包含观测、动作、总奖励、奖励分项、is_first、is_last、is_terminal、场景种子和诊断指标。
  • 日志诊断字段不进入智能体观测和Replay。
  • 可使用规则策略或PPO成功轨迹预填Replay，但记录来源、数量和比例。
  • 改变观测维度必须新建Replay；只改变场景难度时可迁移权重并重新采集。
  • 每阶段保存迁移初始点、最佳验证点和最终点；最佳点按固定验证成功率选择，碰撞率作为并列条件。
  • 长期保留最佳/最终权重、配置、指标和评测；中间权重在复现后归档。
  • 训练使用持久会话，系统重启从最近完整检查点恢复。

11. 独立评测与验收体系

  • 训练、验证和测试种子严格分开；测试采用确定性策略，不更新网络或Replay。
  • 每种场景至少100～200回合；论文主结果使用3个训练随机种子。
  • DreamerV3与PPO使用相同场景实例清单，而不仅是相同概率分布。
  • 报告均值、标准差、95%置信区间和最差分位。

泛化矩阵

  • 未见起终点和更长距离。
  • 未见障碍相位、轨迹组合和冲突方向。
  • LiDAR/状态噪声、随机丢帧。
  • 100～300 ms观测或控制延迟。
  • 质量、惯量、电机推力和响应变化。
  • 持续侧风和短时阵风。

目标为相对标准测试下降不超过15个百分点；未达到时保留失败分布并明确适用边界。

13. 可视化与失败分析

训练监控

  • RSSM动力学、表示、观测、奖励和连续性损失。
  • Actor、Value、想象回报、策略熵和梯度。
  • 成功、碰撞、越界、超时和Replay统计。
  • 训练速度、CPU/GPU、显存和内存。

仿真实况

  • PyBullet画面、轨迹、起终点和障碍。
  • 8帧LiDAR、极坐标扫描、威胁障碍状态。
  • RSSM或编码特征。
  • 距离、速度、净空、动作和安全修正。
  • 降落平台误差、高度、接触和电机转速。

失败分类包括碰撞、越界、超时、飞过终点、目标附近盘旋、贴边捷径、狭窄通道犹豫、迎面反应过晚、双威胁选择错误、垂直冲突忽略和降落不稳。每类保留种子、轨迹、遥测和视频。

14. PX4＋Gazebo软件在环验证

训练策略 → 观测转换 → 单位/坐标转换 → 速度/偏航指令 → ROS 2 → PX4 Offboard → Gazebo x500
  1. 固定PX4、ROS 2和Gazebo版本，验证通信与Offboard状态机。
  2. 独立完成起飞、悬停、速度控制、刹停和降落。
  3. 核对ENU/NED、世界/机体坐标、符号、单位、频率和限幅。
  4. 加载策略完成固定目标无障碍导航。
  5. 加入静态障碍，再加入一个低速动态障碍。
  6. 测试推理延迟、控制超时保护和策略失效刹停。

至少20次固定流程，目标成功率≥70%，P95推理延迟＜100 ms。结果只用于工程可行性，不作为实机或Sim2Real证明。

15. 风险控制与降级路线

风险信号处理
DreamerV3不稳定想象回报升高但真实成功下降回退最佳点、缩短想象、降低学习率、检查奖励模型。
算力不足训练周期过长或显存不足小模型、单环境、小batch；保留PPO完整基线。
Replay质量差大量短失败、无成功样本降低难度，用规则/PPO预填，混合近期与均匀采样。
奖励漏洞贴边、等待、高速飞过记录分项，固定六项奖励，用行为指标审计。
场景无解不同算法同种子均失败几何可通行检查，无解样本单独标注。
Gazebo下降振荡、方向错误、延迟固定场景校准接口，仅小规模微调。
PX4超期通信或版本长期阻塞降级为固定流程，不影响PyBullet主结论。
连续两次独立评测退化时停止增加难度，回退最佳检查点并分析；不得只延长训练掩盖接口、奖励或场景问题。

结语

本计划以“物理可信、接口统一、课程渐进、评测独立、结论克制”为原则。最终目标不是单纯展示无人机能够绕障，而是形成世界模型是否真正改善动态四旋翼导航的完整证据链：公平基线、样本效率、困难冲突安全收益、系统消融、未见场景泛化和PX4/Gazebo工程闭环。
